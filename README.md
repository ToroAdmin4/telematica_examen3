# Examen 3 - Diseño e Implementación de Servicios Telemáticos

## Descripción del Proyecto
Este proyecto demostrará la competencia en el diseño e implementación de un servicio telemático a nivel de producción, utilizando un despliegue continuo y automatizado basado en contenedores Docker sobre una infraestructura en la nube.

## Requisitos del Entorno
- Sistema Operativo: Linux (Ubuntu Server recomendado)
- Git para la gestión del código fuente
